# STORE

A simple grocery and sari-sari store catalog with retail and wholesale ordering.

## Current MVP

- Product catalog with categories
- Product search
- Retail / wholesale price switch
- Buyer quantity controls
- Automatic order totals
- Basic stock display
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

The next stages will add persistent products, inventory management, customer accounts, order tracking, promotions, and reporting.
